# Task Manager Platform

Bu çalışma alanı iki parçaya ayrıldı:

- `backend`: Spring Boot REST API iskeleti
- `frontend`: React tabanlı kullanıcı arayüzü

## Tasarım Yönü

Arayüz için koyu zemin, sarı ana vurgu ve mavi yardımcı vurgu seçildi. Referans görsellerdeki hissi korumak için yüksek kontrastlı kartlar, cam efekti ve net tipografi kullanıldı.

## Dokümantasyon

Geliştirme süreci ve alınan kararlar `docs/` altında tutuluyor.

## Çalıştırma Notu

Backend varsayılan olarak PostgreSQL kullanır. Lokal geliştirmede `backend/docker-compose.yml` içindeki `postgres` servisinin çalışıyor olması gerekir; `run-backend.bat` bunu otomatik başlatmayı dener.
